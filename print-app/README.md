# 3D프린터 출력 요청·이용기록 앱

학생이 **예약 → 요청서 작성 → 출력 확인 → 출력 완료 사진 → 수령 → 활용 사진**까지 한 곳에 남기는 웹앱입니다.
checkin-app과 같은 방식(빌드 없는 HTML/JS + Firebase Firestore, Vercel 배포)입니다.

## 역할 3단계

| 역할 | 들어가는 곳 | 할 수 있는 일 |
|---|---|---|
| 이용 학생 | 첫 화면 | 출력 예약·요청서, 진행 현황판, 내 요청 조회(접수번호+비밀번호), 수령 확인, 활용 사진 등록, 카톡 공유 |
| 매니저(근로학생) | `#/staff` + `MANAGER_PIN` | 예약 확정/반려, 출력 시작, 출력 완료 사진 등록, 수령 처리, 카톡 안내 문구 복사·문자 발송, 메모 |
| 관리자(담당자) | `#/staff` + `ADMIN_PIN` | 매니저 기능 + 실적 통계, CSV 내보내기, 상태 정정, 처리자 이력 확인 |

로그인 시 입력한 이름이 모든 처리 이력에 남습니다(예: `매니저 이매니저`).

## 진행 상태

`접수 → 예약 확정 → 출력 중 → 출력 완료(사진) → 수령 완료 → 활용 등록(사진)` / 예외: `반려`, `취소`
반려·취소되면 예약 시간이 자동으로 다른 학생에게 열립니다.

## 진행 현황판 (`#/board`, 공개)

- 날짜별 장비 예약표, 진행 단계별 요청 목록
- 이용 기록: 일자·학과·학번·이름·3D프린터운용기능사 자격증 여부·출력물·상태
  (공개 화면이므로 이름·학번 일부는 `홍*동`, `2025****`처럼 가림. 운영자 화면에서는 전체 표시)

## 설정 (`config.js`)

- `MANAGER_PIN`, `ADMIN_PIN` — 학기마다 변경 권장
- `PRINTERS`, `SLOTS`, `MAX_SLOTS_PER_REQUEST`, `BOOKING_DAYS_AHEAD`, `CLOSED_WEEKDAYS`, `CLOSED_DATES`, `MATERIALS`
- `KAKAO_JS_KEY`(선택), `KAKAO_CHANNEL_URL`(선택) — 아래 카카오톡 연동 참고

## 배포

1. Firebase 콘솔 → Firestore → **규칙** 탭에 `firestore.rules` 전체를 붙여넣고 게시
   (checkin-app 규칙이 포함되어 있어 같은 프로젝트를 써도 기존 앱이 그대로 동작)
2. Vercel → Add New Project → 이 저장소 → **Root Directory `print-app`** → Framework "Other" → Deploy
3. 학생용 링크: `https://<프로젝트>.vercel.app` / 운영자: `.../#/staff`

사진은 브라우저에서 1280px JPEG로 압축해 Firestore 문서에 저장합니다(Storage 유료 요금제 불필요).

## 카카오톡 연동

| 방법 | 난이도/비용 | 내용 |
|---|---|---|
| ① 공유 버튼 (기본 탑재) | 없음 | 학생이 접수 후 "카카오톡으로 나에게 보내기" → 휴대폰 공유창에서 카톡 선택 |
| ② 카톡 안내 문구 복사 (기본 탑재) | 없음 | 매니저가 상태별 안내문+링크를 복사해 학생 카톡/단톡방에 붙여넣기 |
| ③ 카카오 SDK 공유 | 무료 | developers.kakao.com 앱 생성 → JavaScript 키를 `KAKAO_JS_KEY`에, 플랫폼→Web에 배포 도메인 등록 → 카톡 공유창이 바로 열림 |
| ④ 카카오톡 채널 | 무료 | 센터 채널 개설 → 채팅 링크를 `KAKAO_CHANNEL_URL`에 → 첫 화면에 "채널로 문의" 버튼. 채널 메뉴에 이 앱 링크를 걸어두면 접근성↑ |
| ⑤ 알림톡 자동 발송 | 건당 약 8~15원 + 서버 | 비즈니스 채널 인증 + 발송대행사(솔라피 등) + Firebase Functions(Blaze 요금제) 필요. 상태 변경 시 자동 알림 |

## 예약 없이 운영할 때: `3D프린터_이용기록부_양식.xlsx`

- `이용기록` 시트: 이용일자·학과·학번·이름·자격증·장비·출력물·목적·재료·출력시간·처리 매니저·완료사진·수령·활용사진·활용내용
  (노란 칸은 드롭다운, 첫 행은 예시)
- `월별 집계` 시트: 월별 이용 건수, 자격증 소지 건수, 활용 사진 등록 수, 출력시간 합계 자동 계산
- 사진은 공유 드라이브 `/3D프린터/날짜_이름/` 폴더에 저장하고 시트에 O 표시
