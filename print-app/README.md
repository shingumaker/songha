# 신구대학교 메이커스페이스 3D프린터 출력 예약 (v2)

신구대학교 창의융합혁신센터 3D프린팅룸(미래창의관 B1)의 방문 예약·이용기록·프린터 현황 관리 웹앱입니다.
빌드 없는 HTML/JS + Firebase(익명·구글 로그인, Firestore), Vercel 배포. 확정 명세: `SPEC.md`

## 역할과 흐름

| 역할 | 접속 | 하는 일 |
|---|---|---|
| 학생 | 첫 화면 (자동 로그인) | 방문 예약(학번·이름·자격증·날짜·시간·파일 수) → 내 현황판(본인 기록만) → 수령 확인 → 활용 사진 → 만족도 조사 |
| 매니저(근로학생) | `#/staff` 구글 로그인 | 오늘 방문 예약 처리, 현장 요청서 내용을 이용기록으로 입력, 노쇼 처리, 전체 현황, 프린터 상태 |
| 관리자 | `#/staff` 구글 로그인 | 매니저 기능 + 통계, 시간당 정원, 운영자 관리, 학생 비밀번호 초기화, 엑셀·보고서 내려받기, 공용 PC 설정 |

학생 진행 단계: ① 방문 예약 ② 현장 요청서 작성(당일 센터) ③ 출력 ④ 수령 완료 ⑤ 활용 사진 등록 ⑥ 만족도 조사

- **정원**: 시간당 출력 파일 10개(관리자 화면에서 변경), 1인 최대 5개. 서버 규칙이 초과 예약을 거부합니다.
- **프린터 23대**: 1~22번 메이커봇 리플리케이터+(PLA), 23번 스케치 스프린트. 파일 1개 = 1대.
  이용기록에서 장비를 고르고 "출력 시작" → 자동 '출력 중'(사용자·파일 n/N 표시), 출력 완료 저장 → 자동 '사용 가능'.
  점검·고장·관리자 사용은 프린터 화면에서 직접 변경.
- **다른 기기 조회**: 학번 + 비밀번호 4자리(처음 예약 때 등록). 분실 시 관리자가 초기화.
- **노쇼**: 예약 30분 경과 미방문 시 근로학생이 처리, 학생별 누적 기록.
- **내려받기**: 엑셀(이용기록·노쇼·월별 집계 시트), 보고서(.docx — 이용기록별 정보 표와 사진 포함. 한글에서 열어 HWPX로 저장).

## 배포 체크리스트

1. Firebase 콘솔 → Authentication → 로그인 방법: **익명**, **Google** 사용 설정 → 설정 → 승인된 도메인에 Vercel 주소 추가
2. Firestore → 규칙: `firestore.rules` 전체 붙여넣고 게시
3. Firestore → 데이터: 아래 두 문서를 직접 생성
   - `printStaff/{담당자 구글 이메일(소문자)}` : `role` = `admin`, `name` = 이름
   - `printSettings/main` : `capacity`(number) = `10`
4. Vercel → 새 프로젝트 → 이 저장소 → Root Directory `print-app` → Framework "Other" → Deploy
5. `…/#/staff` 관리자 로그인 → 관리 → 근로학생 이메일을 매니저로 추가
6. 센터 공용 PC: 관리자 로그인 → 관리 → "이 기기를 공용 PC로 사용" 체크 → 로그아웃
7. 테스트 예약 1건으로 예약 → 이용기록 → 수령 → 만족도, 엑셀·보고서 내려받기를 한 번 확인

## 개인정보

비밀번호는 해시로만 저장. 사진은 업로드 전 압축·위치정보 제거, 얼굴·학생증 촬영 금지 안내.
보유 기간(`RETENTION_MONTHS`, 기본 12개월) 경과 기록은 파기해야 합니다(파기 기능은 v1에서 v2로 옮기는 중 — 아래 참고).
