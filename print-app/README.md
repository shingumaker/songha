# 3D프린터 출력 요청·이용기록 앱

학생이 **예약 → 요청서 작성 → 출력 확인 → 출력 완료 사진 → 수령 → 활용 사진**까지 한 곳에 남기는 웹앱입니다.
checkin-app과 같은 방식(빌드 없는 HTML/JS + Firebase Firestore, Vercel 배포)입니다.

## 역할 3단계

| 역할 | 로그인 | 할 수 있는 일 |
|---|---|---|
| 이용 학생 | 자동(익명 로그인) | 예약·요청서, 진행 현황판, 내 요청 조회(접수번호+비밀번호), 수령 확인, 활용 사진 등록, 카톡 공유 |
| 매니저(근로학생) | `#/staff` → 구글 로그인 (관리자가 등록한 계정만) | 예약 확정/반려, 출력 시작, 출력 완료 사진, 수령 처리, 카톡 안내 문구 복사, 메모 |
| 관리자(담당자) | `#/staff` → 구글 로그인 | 매니저 기능 + 실적 통계, CSV, 상태 정정, 처리 이력, **운영자 관리, 공용 PC 설정, 기록 파기** |

처리 이력에 처리자 이름이 남습니다(예: `매니저 이근로`). 운영자는 30분, 공용 PC 학생은 3분 미사용 시 자동 로그아웃됩니다.

## 개인정보 보호 구조

| 항목 | 처리 방식 |
|---|---|
| 연락처 | 수집하지 않음 (규칙에서 저장 자체를 거부) |
| 이름·학번·파일 링크·사진 | `printRequests`(비공개): 본인(접수한 기기 또는 비밀번호로 연 기기)과 등록된 운영자만 읽기 |
| 현황판 | `printPublic`: 가린 이름(홍*동)·학번(2025****)·학과·자격증·출력물명·상태만 공개 |
| 조회 비밀번호 | 저장하지 않음. SHA-256 해시를 키로만 사용(`printKeys`, 읽기 불가) |
| 운영자 권한 | `printStaff/{구글 이메일}`에 등록된 계정만. 화면이 아니라 **서버 보안 규칙**에서 검사 |
| 공용 PC | 관리자가 기기별로 "공용 PC" 설정 → 기기에 기록 미저장, 이용 종료 버튼, 자동 초기화 |
| 보유 기간 | `RETENTION_MONTHS`(기본 12개월) 지난 기록을 관리자가 일괄 파기 → 통계용 항목만 남김 |
| 동의 | 요청서에 수집 항목·목적·보유기간·공개 범위·거부권 명시, 동의 시각 기록 |
| 사진 | 업로드 전 "얼굴·학생증 금지" 안내 + 확인 체크, 재압축으로 위치(GPS) 정보 제거 |
| CSV | 관리자만, 내려받기 전 취급 주의 안내, 엑셀 수식 주입 방지 |

## 진행 상태

`접수 → 예약 확정 → 출력 중 → 출력 완료(사진) → 수령 완료 → 활용 등록(사진)` / 예외: `반려`, `취소`
반려·취소되면 예약 시간이 자동으로 다른 학생에게 열립니다.

## 진행 현황판 (`#/board`, 공개)

- 날짜별 장비 예약표, 진행 단계별 요청 목록
- 이용 기록: 일자·학과·학번·이름·3D프린터운용기능사 자격증 여부·출력물·상태
  (공개 화면이므로 이름·학번 일부는 `홍*동`, `2025****`처럼 가림. 운영자 화면에서는 전체 표시)

## 설정 (`config.js`)

- `PRINTERS`, `SLOTS`, `MAX_SLOTS_PER_REQUEST`, `BOOKING_DAYS_AHEAD`, `CLOSED_WEEKDAYS`, `CLOSED_DATES`, `MATERIALS`
- `RETENTION_MONTHS`, `STAFF_IDLE_MINUTES`, `SHARED_IDLE_MINUTES`, `PRIVACY_CONTACT`
- `KAKAO_JS_KEY`(선택), `KAKAO_CHANNEL_URL`(선택)

## 배포 (처음 한 번)

1. Firebase 콘솔 → **Authentication → 시작하기 → 로그인 방법**에서 **익명**과 **Google**을 사용 설정
2. Authentication → 설정 → **승인된 도메인**에 Vercel 주소(`<프로젝트>.vercel.app`) 추가
3. Firestore → **규칙** 탭에 `firestore.rules` 전체를 붙여넣고 게시
   (checkin-app 규칙 포함 — 같은 프로젝트를 써도 기존 앱 정상 동작)
4. Firestore → **데이터** 탭 → 컬렉션 `printStaff` 시작 → 문서 ID = **담당자 구글 이메일(소문자)**,
   필드 `role`(string) = `admin`, `name`(string) = 이름 → 저장 (첫 관리자 등록)
5. Vercel → Add New Project → 이 저장소 → **Root Directory `print-app`** → Framework "Other" → Deploy
6. `.../#/staff`에서 관리자로 로그인 → "운영자 관리"에서 근로학생 구글 이메일을 매니저로 추가
7. 센터 공용 PC에서는 관리자로 한 번 로그인해 "이 기기를 공용 PC로 사용"을 켠 뒤 로그아웃

사진은 브라우저에서 1280px JPEG로 압축해 Firestore에 저장합니다(Storage 유료 요금제 불필요).

## 테스트

Firebase 에뮬레이터로 검증: 보안 규칙 47개 항목(타인 열람·위조·권한 상승·중복 예약 차단, 파기 등),
화면 전체 흐름(학생 예약 → 타 기기 비밀번호 조회 → 미등록 계정 차단 → 관리자 매니저 등록 →
매니저 처리·완료 사진 → 학생 수령·활용 사진 → 관리자 이력 확인·파기 후 열람 차단).

## 카카오톡 연동

| 방법 | 난이도/비용 | 내용 |
|---|---|---|
| ① 공유 버튼 (기본 탑재) | 없음 | 학생이 접수 후 "카카오톡으로 나에게 보내기" → 휴대폰 공유창에서 카톡 선택 |
| ② 카톡 안내 문구 복사 (기본 탑재) | 없음 | 매니저가 상태별 안내문+링크를 복사해 학생과의 카톡 대화에 붙여넣기 (이름은 가려진 형태) |
| ③ 카카오 SDK 공유 | 무료 | developers.kakao.com 앱 생성 → JavaScript 키를 `KAKAO_JS_KEY`에, 플랫폼→Web에 배포 도메인 등록 → 카톡 공유창이 바로 열림 |
| ④ 카카오톡 채널 | 무료 | 센터 채널 개설 → 채팅 링크를 `KAKAO_CHANNEL_URL`에 → 첫 화면에 "채널로 문의" 버튼. 채널 메뉴에 이 앱 링크를 걸어두면 접근성↑ |
| ⑤ 알림톡 자동 발송 | 건당 약 8~15원 + 서버 | 휴대폰 번호가 필요하므로 현재 구조(연락처 미수집)에서는 사용하지 않음 |

## 예약 없이 운영할 때: `3D프린터_이용기록부_양식.xlsx`

- `이용기록` 시트: 이용일자·학과·학번·이름·자격증·장비·출력물·목적·재료·출력시간·처리 매니저·완료사진·수령·활용사진·활용내용
  (노란 칸은 드롭다운, 첫 행은 예시)
- `월별 집계` 시트: 월별 이용 건수, 자격증 소지 건수, 활용 사진 등록 수, 출력시간 합계 자동 계산
- 사진은 공유 드라이브 `/3D프린터/날짜_이름/` 폴더에 저장하고 시트에 O 표시
