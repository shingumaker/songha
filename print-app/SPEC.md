## 역할
- 학생(익명 로그인): **본인 기록만** 열람. 전체 현황판 없음.
- 매니저(근로학생, 구글 로그인, printStaff 등록): 오늘 방문 예약, 이용기록 입력, 노쇼 처리, 전체 현황판, 프린터 상태.
- 관리자: 매니저 기능 + 통계, 운영자 관리, 프린터 관리·시간당 수용량 설정, 엑셀/한글 보고서 내려받기, 파기, 공용 PC 설정.

## 학생 흐름 (진행 현황 6단계)
1. 방문 예약: 학번, 이름, 자격증(소지/미소지/취득 준비 중), 날짜, 시간(09~17시 1시간 단위), **파일 수(1인 최대 5)**, 조회 비밀번호 4자리, 개인정보 동의.
   - **시간당 출력 가능 파일 10개**(관리자가 조정). 남은 자리 < 파일 수면 선택 불가.
2. 현장 요청서 작성(당일 센터, 종이) — 근로학생이 상태 처리
3. 출력 (근로학생이 이용기록 입력 시 장비 선택 → 장비 자동 '출력 중')
4. 수령 완료 (학생이 확인)
5. 활용 사진 등록 (학생, 최대 3장 + 활용 내용, 얼굴·학생증 금지 안내)
6. 만족도 조사 (별점 1–5, 재이용 의향 네/보통/아니요, 개선 의견)
- 다른 기기 조회: 학번 + 비밀번호.
- 연락처 수집 안 함.

## 근로학생 이용기록 입력
- 오늘 방문 예약자 선택 → 학번·이름·자격증·예약시간 자동.
- 입력: 학과, 출력물명, 목적, 장비(파일 1개 = 프린터 1대, 파일 수만큼 장비 선택, 사용 가능 장비만), 재료·색상, 수량, 출력 시작/종료, 결과(성공/부분 실패·재출력/실패), 완료 사진, 메모, "현장 요청서 작성·서명 확인" 체크.
- 노쇼 처리 버튼(예약 30분 경과 미방문) → 노쇼 기록(학생별 누적, 처리자) 보존.

## 프린터 23대
- 1~22번 메이커봇 리플리케이터+ (PLA), 23번 메이커봇 스케치 스프린트(재료 미정).
- 상태: 사용 가능 / 출력 중(사용자 이름·학번·파일 n/N·종료 예정) / 관리자 사용 중(목적) / 점검 중(사유) / 고장(사유).
- 이용기록에서 장비 선택 시 자동 출력 중, 출력 완료 기록 시 자동 사용 가능.

## 내려받기 (관리자)
- 엑셀(.xlsx): 이용기록 시트, 노쇼 시트, 월별 집계 시트. 기간 선택.
- 보고서 한글(.hwpx) (+ 대체 .docx): 표지, 운영 요약 표, 이용기록 1건당 정보 표 + 완료·활용 사진, 노쇼 표, 만족도 의견.

## 보안 (기존 v1 구조 유지·확장)
- printRequests(비공개): 본인(ownerUid/학번+비번 grant) + 운영자만. printPublic(공개 요약)은 **폐지** — 학생은 전체 열람 불가.
- 슬롯: 시간별 수용량 카운트(트랜잭션) — printSlotCounts/{date_hour} {count}.
- 기존 규칙 테스트(에뮬레이터) 방식으로 재검증.

## 추가 결정 (적용 중)
- **운영자 화면(매니저·관리자)은 포스터 톤 대신 깔끔한 업무용 디자인**: 흰 배경, 얇은 회색 테두리(#E5E7EB), 그림자·굵은 외곽선 없음, 청록 #1F9D7F 한 가지 강조색, 표 중심 레이아웃, Noto Sans KR. 학생 화면만 포스터 톤.
- 진행 상태 값: booked → onsite → printing → done → received → used → surveyed / noshow / canceled.
